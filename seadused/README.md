# Seadused · Laws

Eesti seaduste terviktekstid, igaüks oma kaustas (`seadused/<lühend>/`, nt `seadused/kars/` on karistusseadustik), üks fail paragrahvi kohta; põhiseadus on kaustas [`ps/`](../ps/), seadused Riigikogus vastuvõetud kujul kaustas [`riigikogu/seadused/`](../riigikogu/seadused/). Kuni 17. novembrini 2026 olid need kaustad repositooriumi juurkaustas; [`data/paths.json`](../data/paths.json) näitab iga kausta varasemat asukohta. Osa terviktekste (lahend.ee-st) on **veel kontrollimata**: seda ütleb akti enda README.

Consolidated texts of Estonian laws, one folder each (`seadused/<abbreviation>/`, e.g. `seadused/kars/` is the Penal Code), one file per section; the Constitution is in [`ps/`](../ps/), and the laws as the Riigikogu adopted them are in [`riigikogu/seadused/`](../riigikogu/seadused/). Until 17 November 2026 these folders were at the top of the repository; [`data/paths.json`](../data/paths.json) gives each one's earlier place. Some texts (from lahend.ee) are **not yet validated**: the act's own README says so.

35 laws on 2026-11-17.
